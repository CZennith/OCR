# OCR Project

## Introduction
This is a project I created to play around with the OCR Engine and with Python GUIs (Tkinter in this case). 
What I have created here is a simple program that allows the user to convert texts within images (.png, .jpg) into text within written documents (.txt, .odt, .md). 

Though this is a small and simple project, to use this programme there are 2 steps you have to do.

## Set up
To utilise this program, you must: 
1. Download the [Tesseract OCR Engine](https://tesseract-ocr.github.io/tessdoc/Downloads.html) into your local computer. You can refer to UB Mannheim for installers that are up-to-date.
2. Set the installed Tesseract OCR Engine to path.
3. Download the required resources in the requirements.txt file by running `pip install -r requirements.txt`

## The Program
The program is simple. Browse the image you want to extract the text from and save it with "Append" or "Overwrite" as your options.
